# Linux Tools

This directory is reserved for Linux related tools.

## qfirehose

The start_flash_linux.sh script is meant to be made executable (chmod +x) and placed in the same directory as (next to) the update directory for the target firmware.
Please note that qfirehose must be placed in your $PATH (recommend placing at /usr/bin/qfirehose )

Choose the qfirehose for your system arch. Pre-built x64, arm64, and arm are avalible
